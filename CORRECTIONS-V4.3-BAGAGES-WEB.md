# YAM TRANS Serveur/Web v4.3 — Bagages

- Interface Web complète avec routes dédiées `/app/bagages/*`.
- Même module Bagages que l’application Android : accompagné/non accompagné, ticket facultatif, reçu, étiquette QR, voyages, chargement, arrivée, retrait, manifestes et recettes.
- Voyage partagé avec Tickets.
- Modules Bagages configurables par société et par utilisateur.
- Synchronisation serveur étendue à `ticket_baggage`, `ticket_reservations` et `loyalty_transactions`.
- Migration additive : aucune suppression des tables ou données existantes.
