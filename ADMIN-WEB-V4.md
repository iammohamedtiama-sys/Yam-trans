# Console Web YAM TRANS

Après déploiement du serveur, ouvrir `/admin-web` sur le domaine de synchronisation.

Connexion : utiliser un compte `platform_admin` avec la société `PLATFORM`.

La console ne remplace pas les applications d'agence : elle est destinée à la supervision centrale de toutes les sociétés, des utilisateurs, des modules, des recettes, des opérations et des communications.
