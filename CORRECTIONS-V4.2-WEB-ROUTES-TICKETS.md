# YAM TRANS serveur/web v4.2

Le portail Web n’est plus une page statique unique : chaque écran métier possède une URL dédiée sous `/app/`. Les routes profondes servent l’application sans erreur 404 et les ressources Vite sont publiées sous `/app/assets/`.

Exemples : `/app/courrier/envois`, `/app/tickets/vente`, `/app/tickets/voyages`, `/app/tickets/manifestes`, `/app/tickets/bagages`, `/app/fidelite/tickets`, `/app/administration`.
